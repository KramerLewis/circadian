# App Store submission checklist

| | Item | Where |
|---|---|---|
| ✅ | App icon (default, dark, tinted) | `ios/SunClock/Assets.xcassets`, `ios/tools/make_app_icon.py` |
| ✅ | Privacy manifests (app, widgets, Watch) | `PrivacyInfo.xcprivacy` in each target |
| ✅ | Privacy policy + support pages | `docs/privacy.md`, `docs/support.md` (GitHub Pages) |
| ✅ | Export compliance (no non-exempt encryption) | `ITSAppUsesNonExemptEncryption = NO` |
| ✅ | License, changelog, security policy | repo root |
| 📝 | Listing copy | [`listing.md`](listing.md): review and edit |
| 📝 | Review notes | [`review-notes.md`](review-notes.md) |
| 🔄 | Screenshots, 6.9" iPhone | generated by CI to the `screenshots` branch, `app-store/` |
| ⬜ | Accessibility pass on device (VoiceOver, large text) | after TestFlight |
| ⬜ | Name availability, pricing | App Store Connect |
| ⬜ | TestFlight build, then submit | after enrollment |
